## 2. Accès au service

L'accès au service nécessite :
- un compte Telegram ;
- une formule active : abonnement mensuel payant, accès à vie (paiement unique) ou accès gratuit accordé par un administrateur (code à usage unique).

Le service est fourni "en l'état". CelluleTrade s'efforce d'assurer une disponibilité continue mais ne garantit pas une disponibilité ininterrompue (maintenance, panne du fournisseur d'hébergement, indisponibilité des API tierces Binance/Alchemy/Telegram).

## 3. Clés API Binance

L'utilisateur est seul responsable des clés API qu'il fournit. Il est fortement recommandé de :
- créer une clé API **dédiée** à CelluleTrade ;
- **ne jamais activer les droits de retrait (withdrawal)** sur cette clé ;
- limiter si possible les droits à la lecture seule (lecture des dépôts/soldes).

CelluleTrade ne demande et n'utilise à aucun moment de droits de trading ou de retrait. Les clés API sont stockées chiffrées (voir Politique de confidentialité).

## 4. Abonnements et paiements

- **Abonnement mensuel** : reconductible, facturé via Stripe.
- **Accès à vie** : paiement unique via Stripe, donnant un accès permanent au service.
- **Accès gratuit** : accordé par un administrateur via un code à usage unique, sans limite de durée.

Les paiements sont traités par Stripe. CelluleTrade ne stocke aucune donnée de carte bancaire.

- CelluleTrade se réserve le droit de suspendre ou révoquer l'accès d'un utilisateur en cas d'usage abusif, frauduleux, ou de non-respect des présentes CGU.

## 6. Responsabilité

CelluleTrade est un outil de **notification** uniquement. Il n'effectue aucune opération de trading, de dépôt, de retrait ou de transfert de fonds. CelluleTrade ne saurait être tenu responsable :
- de pertes financières liées à l'utilisation de Binance, Rise, ou de tout autre service tiers ;
- d'un retard ou d'une absence de notification dû à une panne d'un service tiers (Binance, Alchemy, Telegram) ;
- d'une mauvaise configuration des clés API ou de l'adresse de wallet par l'utilisateur.
